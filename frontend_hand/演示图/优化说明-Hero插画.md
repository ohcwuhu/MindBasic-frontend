## 二、光影 / 色彩参数（供后续PS微调参考）

### 接触阴影
- 混合模式：Multiply
- 颜色：深绿偏暖棕（#4A5D3A ~ #5C4A3A）
- 不透明度：25–35%
- 高斯模糊：6–14px
- 垂直偏移：向下 4–8px
- 作用区域：男孩鞋底（两只鞋）、女孩裙摆下缘、猫腹部/爪子与草地接触面

### 光源
- 主光方向：左上 45°
- Rim light：人物左缘 + 猫背左缘，1–2px，暖白色（#FFF5E6），不透明度 8–15%
- 猫白毛反光：极浅暖米（#FFF8EE），不纯白
- 死黑描边：已弱化，保留水彩线条但去掉纯黑块

### 色彩
- 远山/背景：饱和度降低 10–20%，色相略微偏冷（蓝灰方向）
- 人物：保持原饱和度和对比度不变
- Halo：人物身后纸米色（#F5EEDF），径向渐变，边缘羽化大，不透明度 5–10%
- 粉发/紫裙：与背景粉山做色相分离（人物粉偏暖粉，背景粉偏灰粉）
- 蓝衣：与远山蓝做明度分离（人物蓝饱和，远山蓝灰淡）

## 三、分层文件清单

> ⚠️ AI 生图工具输出为合并位图（flattened PNG），以下为**建议的 PSD/Procreate 图层结构**，需在设计软件中手动拆分或基于此规范重新组织。当前交付的 PNG/WebP 为整图合并版。

### 建议 PSD 图层结构（从上到下）

```
Layer 1: 前景草（最底部草叶，笔触最强，可做独立层方便Web裁切）
Layer 2: 人物组（男孩 + 女孩，含各自接触影）
Layer 3: 橘白小猫（独立层，方便做交互动效）
Layer 4: 中景花草（黄色/粉色/白色小花，草叶）
Layer 5: 远山（粉蓝远山，最冷最淡）
Layer 6: 纸纹背景（水彩纸纹理 + 淡色渐变）
Layer 7: Halo（人物身后纸米色光晕，叠加层）
```

## 五、仍需手动微调的项（AI生成后建议PS处理）

1. **右缘安全区**：如需严格保证右缘 64–80px 无任何细节，建议在 PS 中对右侧边缘做 40px 的渐变擦除（从透明到纸纹色），或直接裁掉右侧 40px。
2. **人物独立层**：当前为合并位图，如需人物/猫独立透明 PNG 层用于 Web 动效，需在 PS 中用选择工具手动抠出，或使用 remove.bg / 手动钢笔路径。
3. **接触影精度**：AI 生成的阴影方向和强度已大致正确，但精确的 25–35% 不透明度需在 PS 图层样式中微调。
4. **AVIF 导出**：当前交付 WebP，如需 AVIF 可在 PS/Squoosh 中进一步转换（AVIF 压缩率比 WebP 高约 20–30%）。
