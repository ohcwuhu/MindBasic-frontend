这一版的背景是**两张图**：

- **首页**用客户端给的 `首页背景-双人聊天版-人物缩小.png`：**整幅**就是第一屏 —— 首屏的盒子按这幅画自己的
  比例 2730 : 1536 定高（1440 宽 → 1440 × 810），所以画不裁、不拉，两个人画在画里、页面不再叠
  一层插画。画的下沿就是接缝，再往下由**这幅画自己的底边**接出草皮，只留一小段给四张入口便签
  落地（便签骑在接缝上）。页面到那里就结束，下面只有页脚。
- **自我教练页**用客户端给的 `纯水彩草地背景.png`（2590 × 1619，一整幅水彩草地），
  **固定背景**（`cover` + `fixed`）。
- **内层页**默认用客户端给的 `首页背景-纯水彩草地版.png`（2590 × 1619，一张纯草地），
  **固定背景**（`cover` + `fixed`）：按视口算尺寸，页面多长都不会把图拉长变形，往下滚就是
  内容在背景上滑过去。其中**科普中心**换成同系列的「带树」（2730 × 1536）、**真人教练**换成
  「木屋」（2730 × 1536）；首页用「双人聊天版」、自我教练页用「纯水彩草地背景」。

> 固定背景的页面按**一屏**出图：整页截图时浏览器只会把固定背景画一屏，再往下是底色 ——
> 那是截图工具的限制，不是页面本身的样子（在浏览器里滚一下就知道）。

> **自我教练那张的视频区是灰的**（按你的要求改的）：舞台是一块空的视频面，不是插画 ——
> 深灰的一整块，像一块没接上信号的屏。站在右下角浮窗里的是**原组件那套动态 3D 陪伴角色**
> （状态视频 → canvas 黑幕抠像 → 眨眼覆盖层 → 落地阴影），浮窗位置、多模态线索、对话结构都是原样。
> 舞台与浮窗都保持深底：角色是照着深底画、照着深底抠的，垫到亮纸上会发灰、没立体感。
>
> 这一页要**用本地服务打开**才看得到角色：素材走的是站内绝对路径 `/companion/…`，
> `file://` 下取不到（页面其余部分照常）。
>
> 修订：**页面上的胶带已全部删除**（首页四张入口便签、徽章墙，情绪日记的页头与记录卡）。

生成方式是真渲染，不是 AI 效果图：`../demo/*.html` 由本机 Chrome 截图，页面里的字都是真文本，
可以对着图直接开发。

## 重跑

```bash
cd ../demo
node tools/render.mjs            # → 本目录四张图
node tools/render.mjs home       # 只出首页（home / coach / journal / coaches / wide）
```

改样式后重跑即可；同一批校验建议一起跑：

```bash
node tools/verify.mjs        # 横向溢出、越界元素、图片未加载、文字溢出、字体是否命中
node tools/collisions.mjs    # 不该发生重叠的元素对
# 十六个页面共用同一套校验脚本，用 PAGE 指定要跑哪一页（默认 index.html）：
#   PowerShell:  $env:PAGE="coaches.html"; node tools/verify.mjs
#                $env:PAGE="coaches.html"; node tools/collisions.mjs
node tools/boxes.mjs 1440    # 逐个元素的精确坐标，排版问题用数字看
python tools/preview.py <png> [列数] [x,y,w,h]   # 字符画看构图
python tools/rhythm.py  <png> [分段数]           # 整页疏密节奏
```

## 自我教练那张

这一张**就是 `MindBasic-frontend` 那三个组件跑出来的**：`views/VideoCallView.vue` +
`components/ai-lab/VideoCallPanel.vue` + `CompanionSprite.vue` 由 `demo/vue/` 里的构建
（Vite + `@vitejs/plugin-vue`）直接引进来编译，挂在这一页的 `#app` 上 —— 模板、状态机、文案、
socket 协议、组件自带样式一个字没改，这边只换画风（`demo/styles/self-coaching.css`）
和背景图（`纯水彩草地背景.png`）。

所以这一张出的是**通话中**那一屏（原版的第一屏是「通话前」：光球里的角色 + 麦克风/多模态/
摄像头三项授权 + 开始按钮 —— 那一屏另存为 `.cache/review/自我教练-通话前.png`）。图里能看到的
东西：顶栏「服务已连接」+ 状态 chip + 轮次、舞台（摄像头的画面位，摄像头关着就是一块空的
视频面 + 「摄像头已关闭」说明）、右下角的**陪伴角色浮窗**（原组件原来的位置）、侧栏的对话标题 +
多模态线索五路 + 对话流、底栏的音量波形与六个按钮、底部提示那一行。

比例照原代码：控制台整幅铺开、左右各留 16px，侧栏固定 372px、舞台占其余宽度 —— 1440 下是
舞台 1024 : 侧栏 372。整页正好一屏（页头 60 + 通话台 775 + 页脚 65 = 900）。

> 这一页的 3D 角色素材走的是站内绝对路径 `/companion/…`（原项目 `public/companion/`），
> 所以**看动态版本要起本地服务**；`node tools/render.mjs coach` 会自己起一个小静态服务再出图，
> 出图不受影响。

## 情绪日记那张

这一张**就是 `EmotionJournalView.vue` 跑出来的**（连 `MoodFace` / `QuoteBlock` / `EmptyState` /
`ErrorBanner` 一起），由 `demo/vue/` 那份构建编成 `scripts/emotion-journal-app.js` 挂在这一页的
`#app` 上 —— 模板、文案、状态、接口名、组件自带样式一个字没改。所以图上那些内容是原组件的原样：
页头「把此刻写下来」、来自自我教练的提示、此刻的感觉（六个心情）、写一句话 + 字数 + 「记录此刻」、
AI 回应、月历 + 心情记录并排、近 30 天分布、「今日一句」。**这一页是真的能用**（选心情、写字、
提交、删记录、翻月、点某天筛记录），出图时用的是那一版的示例数据。

画风做成**手账**，用的全是素材库 2.0：整页是一张摊开的**手账纸**（`方格纸` 做纸面、纸角一枚
`图钉`）；今天那格用`圈注圆圈`圈一下；
选中的心情盖一枚`对勾`；「今日一句」是一张被`粉色图钉`钉住的黄便签；
**六个心情＝六张表情贴纸**（原组件那张小脸是 SVG 画的，这里整体换成贴纸，心情选择器、
记录卡、近 30 天分布三处同一张）。原版那两个装饰光晕在这套画风里拿掉了。背景是固定背景，
所以**整页出图时画面只画一屏、再往下是底色** —— 那是截图工具的限制，在浏览器里滚一下就知道。
纸的下面还留了 **80px 的地**（原来纸的下沿离页脚只差 2px，页面收得太急）；
「今日一句」那张便签也和上面的「近 30 天分布」拉开了 48px。

## 真人教练那张

结构照 `CoachesView.vue`：标签筛选 + 昵称搜索 + 教练卡（两位一列）。卡里是昵称、从业年数、
标签、服务理念、评分与最近可约；头像用的是素材库的教练象征物（一杯茶、一把椅子、一只猫、一盏灯、
一株植物、一条围巾），牌子是它们各自代表的那位教练。下面一节「预约怎么走」把下单流程讲成三步。

这张出的是**首屏**（固定背景页只出一屏，见上）。另外这一版的页头不再是 540px 高的图片带，
标题下面直接就是内容 —— 第一个框距顶从约 580px 提到 269px。

## 图里的素材与数据

- 所有插画来自 `项目主体/素材库2.0`：小苗八种姿势、六枚徽章、六张文章分类、八个教练象征物、
